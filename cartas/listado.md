## Cartas grises (opción «Dado gris»)

Se saca una por partida, es común y la ven todos.

| Nº | Regla |
|---|---|
| G1 | El jugador con el dado gris debe tener al menos 1 dado de cada color en juego. |
| G2 | El jugador con el dado gris tiene que sumar al menos 15 (incluido el gris). |
| G3 | El jugador con el dado gris no puede tener otro dado con la misma cifra que el dado gris. |
| G4 | El jugador con el dado gris puede tener como máximo 6 dados (incluido el gris). |
| G5 | El jugador con el dado gris debe tener al menos otro dado con la misma cifra que el dado gris. |
| G6 | El jugador con el dado gris no puede tener más de 3 dados de un mismo color. |
| G7 | El jugador con el dado gris no puede sumar más de 15 (incluido el gris). |
